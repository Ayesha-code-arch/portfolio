Projects

The following projects demonstrate my technical skills and collaborative experiences. Each project includes space for images and links to source code on GitHub.

Generative AI for Histopathological Image Synthesis

Developed CycleGAN and diffusion models to translate between H&E and in‑situ hybridisation slides of glioblastoma. Achieved low Fréchet Inception Distance and preserved tissue morphology.

Repository: GitHub

Employee Pay & Satisfaction Analysis

Analysed salary, satisfaction and demographics for 1,470 employees. Performed correlation analysis, t‑tests, ANOVA and chi‑squared tests using R. Visualised key relationships and found no significant gender pay gap.

Repository: GitHub

Exploratory Data Analysis of Montgomery County Crime

Cleaned and analysed more than 300k crime incident records from Montgomery County (2016–2022). Engineered temporal and spatial features, mapped hotspots and explored trends using Python visualisations.

Repository: GitHub

Digit Classification with Classical Machine Learning

Compared eight algorithms on the scikit‑learn digits dataset, using grid search for hyper‑parameter tuning. Achieved 98.6% balanced accuracy and 99.9% macro ROC AUC with a tuned Support Vector Machine.

Repository: GitHub

UK Airport Punctuality Data Warehouse

Designed and built a star‑schema data warehouse integrating 24 monthly flight statistics for 2023–2024. Developed SQL scripts to clean, integrate and load the data and created Tableau dashboards highlighting delays, cancellations and punctuality trends.

Repository: GitHub

Royal Anchor Shipping Database System

Designed a 22‑table relational database to manage vessel scheduling, cargo tracking, bookings and crew operations. Enforced data integrity with primary keys, foreign keys and triggers, and implemented complex queries for reporting.

Repository: GitHub

Deep Learning for Real‑Time Financial Forecasting

Built and compared LSTM, GRU, CNN‑LSTM hybrid and dense networks to forecast Starbucks share prices. The CNN‑LSTM model achieved an R² of approximately 0.889 on the test set.

Repository: GitHub

AWS Glue ETL Lab

Automated an ETL workflow on the GHCN‑D climate dataset using AWS Glue, Athena, CloudFormation and IAM. Created crawlers, Parquet tables and reusable infrastructure templates.

Repository: GitHub

Wine & Hip Fracture Regression Models

Performed linear regression to model red wine quality and logistic regression to predict hip fracture risk. Explained around 32% of variance in wine quality and achieved AUC up to 0.926 for hip fracture prediction.

Repository: GitHub

Support2 EDA for Critical Care Analysis

Explored the SUPPORT2 dataset of 9,105 patients and 48 variables: assessed missingness, outliers, descriptive statistics, correlations and variable coding. Produced insights on severity scores and outcomes.
